## Установка с планшета

1. Откройте ссылку скачивания в браузере планшета.
2. Дождитесь загрузки и откройте файл `dashboard.apk`.
3. Если Android попросит, разрешите установку приложений из этого браузера.
4. Нажмите «Обновить», затем откройте приборную панель.

Для обновления существующего приложения не удаляйте его: обновление с той же
подписью сохраняет настройки и калибровки. При первой установке потребуется
настроить приложение и разрешения автоматики экрана.

Сборка для Samsung Galaxy Tab S6 (Android 12), процессор ARM64.
Текущий APK около 8 МБ. Другие типы процессоров в этот APK не включены.

В этом репозитории размещаются установочные файлы и описания выпусков.
